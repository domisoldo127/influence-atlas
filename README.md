# Influence Atlas

총 10,000명의 경제·금융·기업·기술 인물 사전, 기존 인물 관계도, 공식 자료 기반 자금 흐름을 제공하는 한국어 대시보드입니다. GitHub Pages용 정적 사이트이며 API 키나 유료 서비스가 필요하지 않습니다.

## 2026-10-20 확장

- **1만 명 인물 탐색**: 분야별 분류, 한글·영문 검색, 40명 단위 페이지, 소속 이력과 같은 조직의 인물 탐색.
- **기존 관계도 유지**: 54명·37개 조직·67개 관계, 사진, 관계 설명, 드래그와 확대 기능.
- **자금 흐름**: 공식 거래 7건의 방향·금액·시점·근거. 투자 발표, 지원 한도 확정, 완료·지급 기록을 구분합니다.
- **확인 수준 표시**: 기존 54명과 공개 수집 신규 9,946명을 구분합니다. 1만 명 전원의 현재 직함과 관계를 공식 자료로 개별 확인한 목록은 아닙니다.

[수집 기준·출처·관계 해석·재현 방법](DATA-PROVENANCE.md)을 확인하세요. 아래 이전 기능 기록의 소규모 수치는 기존 `data.json`의 관계도 범위를 뜻합니다.

## 실행

Node.js 20+ / Python 3가 있다면:

```sh
npm test
npm run lint
npm run build
python -m http.server 4176 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:4176/#view=catalog 를 엽니다. `file://`로 열면 JSON을 읽을 수 없으므로 HTTP 서버가 필요합니다.

## GitHub Pages 배포

이 폴더를 저장소 루트로 사용합니다. GitHub 저장소의 Settings → Pages → Source를 **GitHub Actions**로 선택하고 `main` 브랜치에 푸시하면 `.github/workflows/pages.yml`이 테스트 후 배포합니다. 기본 주소는 `https://<owner>.github.io/<repository>/`입니다. 모든 파일 경로는 상대경로이므로 프로젝트 하위 경로에서도 작동합니다.

배포되는 파일은 `index.html`, `styles.css`, `app.js`, `graph.js`, `interactions.js`, `data.json`, `.nojekyll`과 `portraits/`의 인물 사진입니다. 개인 로그인 계정명·알림 설정·작업 기록은 포함하지 않습니다. Google Fonts를 불러올 수 없을 때는 시스템 글꼴로 표시합니다.

## 데이터 편집과 검증

`data.json`의 `nodes`는 관심 계정 46개와 관계 설명용 기업·기관 28개입니다. `edges`는 역할·협력·과거 이력·사업 경쟁을 구분합니다. 각 관계에 출처 URL과 확인 날짜가 있고, 발표 자료에는 발표 당시 날짜도 있습니다. `build-data.mjs`는 초기 데이터 생성 스크립트이며 재실행하면 JSON을 덮어씁니다. 직접 JSON을 수정한 후에는 생성 스크립트를 재실행하지 마세요.

- `affiliation`: 공개 프로필의 역할 또는 창업 이력. 인물 간 지휘·친분을 추정하지 않습니다.
- `partnership`: 공식 발표로 확인한 기업 간 협력·투자. 현재의 모든 계약 조건을 뜻하지 않습니다.
- `history`: 과거 소속.
- `competition`: 공식 제품·사업 영역을 참고한 분석자의 분류. 사실로 확인한 개인 간 갈등이 아닙니다.
- 연결이 없는 인물도 디렉터리에는 표시됩니다. 근거가 없는 관계를 채우지 않습니다.

인물 직함 일부는 2026-09-22 공개 프로필 확인 기록에 근거하며 시간이 지나면 재확인이 필요합니다. 관계의 수나 화면상 위치·크기는 영향력 점수가 아닙니다.

## 현재 제공 기능

인물/계정 검색, 분야 필터, 관계 종류 필터, 노드와 연결선 선택, 근거 패널, 확대·축소·빈 영역 드래그, 키보드 탐색, 계정 디렉터리, 근거 라이브러리, JSON 내려받기, URL 해시를 통한 탐색 상태 공유, 모바일 반응형 화면.

## 발언 수집

현재 X 게시물·인터뷰 수집, 자동 요약, 푸시 알림은 연결되지 않았습니다. `statements`는 빈 배열이고 화면에 연결 대기 상태를 명시합니다. GitHub Pages 자체는 정적 호스팅입니다. 향후 수집기는 별도 실행 환경에서 원문·시각·출처·인물 ID가 있는 데이터를 생성하고 검토 후 정적 JSON으로 반영해야 합니다. 토큰·쿠키 등 비밀정보를 사이트에 넣지 마세요.

## 관계도 조작

아이콘을 드래그하면 연결선도 함께 이동합니다. 아이콘 클릭은 상세 보기, 키보드 방향키는 위치 이동(Shift: 큰 폭 이동)입니다. 빈 공간 드래그로 화면을 이동하고 마우스 휠, 트랙패드 또는 두 손가락 제스처로 확대·축소합니다. 확대 범위는 25–600%이며 포인터 위치를 중심으로 확대합니다.

아이콘 배치는 전체 관계도와 각 분야별로 이 브라우저의 localStorage에 저장됩니다. 페이지를 다시 열거나 관계 필터를 바꾸어도 유지되며 다른 기기와 동기화되지 않습니다. 배율 숫자는 화면 위치와 배율만 초기화하고, ‘배치 초기화’는 현재 분야의 저장된 아이콘 배치도 초기화합니다. 저장이 차단된 브라우저에서는 현재 페이지에서만 유지됩니다.

## 인물사진

인물 37명에 사진을 표시합니다. 34명은 Wikimedia Commons에서 출처·저작자·라이선스를 확인한 썸네일을 portraits/에 저장합니다. 이석희·허이·아서 헤이즈는 공식 소개 페이지의 외부 사진을 참조합니다. 사진별 출처와 이용조건은 data.json의 photo 및 화면의 인물 상세·근거 라이브러리에서 확인할 수 있습니다. 사진은 원형 프레임으로 표시하며 불러오기 실패 시 이니셜을 유지합니다. 외부 원본 주소 변경 시 해당 인물의 photo.url을 갱신하세요.

## 관계 설명

연결 50개에 관계 이름과 문장 설명이 있습니다. 대립·분쟁, 경쟁(해석), 지원·투자, 상하·직무, 협력, 소속·역할, 과거 이력을 구분합니다. 지원과 상하관계만 제공자·상위 책임자에서 상대방을 향하는 화살표로 표시합니다. 인물과 조직의 창업·소속 이력을 개인 간 상하관계로 추론하지 않습니다.

지도 위 관계 이름 또는 아래 설명 카드를 누르면 상세 설명·방향·출처·시점을 확인할 수 있습니다. 유형 버튼을 다시 누르면 모든 관계로 돌아옵니다. 관계 이름은 켜기·끄기가 가능하며 아이콘 드래그 시 선·화살표·이름 위치도 갱신됩니다. 전체 목록은 현재 분야·유형·선택 인물·검색 조건을 따릅니다. 법적 대립 사례는 2025년 3월 당시의 기록이며 현재 소송 상태를 나타내지 않습니다.

## 겹침 없는 관계별 배치

기본 화면은 `관계별 정리`입니다. 각 관계의 양 끝 인물·조직을 별도 칸에 반복 표시하되 원본 인물 데이터와 계정 수는 중복하지 않습니다. 연결 미등록 인물도 별도 칸에 남깁니다. 넓은 화면은 2열, 좁은 화면은 1열이며 스크롤로 모든 관계를 볼 수 있습니다. 통합 지도 버튼으로 기존 전체 네트워크에 전환할 수 있습니다.

분리 배치의 사진은 이름·관계 표시와 겹치지 않도록 각 칸의 지정 영역 안에서 드래그됩니다. 각 복사본의 위치를 분야·관계 필터·열 수별로 저장하며 통합 지도의 저장 배치는 유지합니다. 휠은 목록 스크롤, Ctrl+휠 또는 확대 버튼은 확대·축소입니다. 배치 방식은 URL의 `layout=separated` 또는 `layout=integrated`로 공유합니다.

## 통합 지도 시인성

아이콘 아래 숫자는 현재 분야·관계 필터에서 해당 인물이나 조직에 연결된 관계 수입니다. 반복 아이콘도 원본 인물의 같은 수를 표시하며 영향력 점수가 아닙니다.

통합 지도는 연결된 집단을 독립 영역으로 묶고 각 집단의 원형 순서를 계산해 선 교차를 줄입니다. 현재 74개 노드·50개 관계의 기본 배치는 교차가 없습니다. 사용자가 직접 위치를 바꾸거나 관계 데이터를 추가하면 교차가 생길 수 있으며 배치 초기화로 기본 배치로 돌아갑니다. 선은 아이콘·이름·숫자 영역 바깥에서 시작합니다.

기본은 이름을 읽기 쉬운 넓은 캔버스입니다. 전체 맞춤/읽기 크기로 전환하고 지도 크게 보기로 화면 전체를 사용할 수 있습니다(Escape로 복귀). 관계 이름은 기본적으로 인물·선 선택 또는 선 위에 마우스를 올릴 때 나타나며 전체 표시도 가능합니다. 새 통합 배치는 이전 배치와 별도로 저장합니다.

## 인물과 조직 구분 · 2026-09-23 확장

기본 표시는 인물만이며 URL의 entity=people/all로 전환합니다. 등록 인물은 54명, 회사·기관·프로젝트는 37개로 별도 집계합니다. 회사·기관 함께 버튼으로 기존 조직 관계도 볼 수 있습니다. 인물 전용 화면은 원본에 명시된 인물 간 관계만 표시하며 기업 간 경쟁·투자를 개인 간 관계로 바꾸지 않습니다. 연결 수 역시 현재 표시 대상에 맞춰 계산합니다.

공식 소개와 발표를 확인하여 17명을 추가했습니다. 글로벌 경제: 케빈 해싯, 제이미슨 그리어, 필립 레인. AI: 다니엘라 아모데이, 재러드 캐플런, 아미 보라. 반도체: 콜레트 크레스, 닉 파커, 전영현, 송재혁, 곽노정. 디지털자산: 모니카 롱, 스튜어트 알데로티, 크리스 라슨. 한국 경제: 정의선, 장재훈, 성 김. 닉 파커는 NVIDIA 최신 공식 소개의 2026년 8월 합류 정보를 반영했습니다. 신규 인물의 X 개인 계정·팔로우 상태는 확인하지 않았으며 사진 미등록을 명시하고 이니셜을 표시합니다. 기존 37명의 사진은 유지합니다.

team 관계는 공식 자료에 함께 기재된 경영진·집행부를 뜻하며 방향 화살표를 쓰지 않습니다. 직접 보고나 개인적 친분을 추정하지 않습니다. 데이터 전체는 91개 항목·67개 관계이며 현재 기본 배치의 인물 모드와 조직 포함 모드 모두 선 교차가 없는 것을 검증합니다. 배치 저장은 표시 대상과 데이터 버전별로 구분됩니다.

## 한눈에 보는 관계 보드

기본 배치는 layout=board입니다. 연결된 인물을 집단별 작은 관계도로 배치하며 사진·이름·직책·연결 수와 관계 이름을 함께 표시합니다. 인물 모드는 7개 집단, 23명의 연결을 먼저 보여주고 관계 미등록 31명은 버튼으로 펼칩니다. 회사·기관 함께 모드에서도 원본 관계를 모두 보존하며 반복 인물 수는 중복 집계하지 않습니다.

인물 상세의 이 인물의 관계만 보기 또는 선택 인물 중심으로 버튼으로 바로 연결된 주변만 탐색합니다. 전체 관계로 돌아가기 버튼으로 복귀합니다. 관계 이름을 누르면 설명·방향·출처가 상세 창에 열립니다. 자유 지도(layout=integrated)와 관계별 목록(layout=separated)은 계속 사용할 수 있습니다. 참조한 사례와 구현 원칙은 DESIGN-REFERENCES.md에 정리했습니다.
