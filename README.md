# Influence Atlas

46개 공개 X 계정을 바탕으로 만든 한국어 인물·기업 관계 대시보드. GitHub Pages용 정적 사이트이며 API 키나 유료 서비스가 필요하지 않습니다.

## 실행

Node.js 20+ / Python 3가 있다면:

```sh
npm test
python -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. `file://`로 열면 JSON을 읽을 수 없으므로 HTTP 서버가 필요합니다.

## GitHub Pages 배포

이 폴더를 저장소 루트로 사용합니다. GitHub 저장소의 Settings → Pages → Source를 **GitHub Actions**로 선택하고 `main` 브랜치에 푸시하면 `.github/workflows/pages.yml`이 테스트 후 배포합니다. 기본 주소는 `https://<owner>.github.io/<repository>/`입니다. 모든 파일 경로는 상대경로이므로 프로젝트 하위 경로에서도 작동합니다.

배포되는 파일은 `index.html`, `styles.css`, `app.js`, `graph.js`, `data.json`, `.nojekyll`뿐입니다. 개인 로그인 계정명·알림 설정·작업 기록은 포함하지 않습니다. Google Fonts를 불러올 수 없을 때는 시스템 글꼴로 표시합니다.

## 데이터 편집과 검증

`data.json`의 `nodes`는 관심 계정 46개와 관계 설명용 기업·기관 28개입니다. `edges`는 역할·협력·과거 이력·사업 경쟁을 구분합니다. 각 관계에 출처 URL과 확인 날짜가 있고, 발표 자료에는 발표 당시 날짜도 있습니다. `build-data.mjs`는 초기 데이터 생성 스크립트이며 재실행하면 JSON을 덮어씁니다. 직접 JSON을 수정한 후에는 생성 스크립트를 재실행하지 마세요.

- `affiliation`: 공개 프로필의 역할 또는 창업 이력. 인물 간 지휘·친분을 추정하지 않습니다.
- `partnership`: 공식 발표로 확인한 기업 간 협력·투자. 현재의 모든 계약 조건을 뜻하지 않습니다.
- `history`: 과거 소속.
- `competition`: 공식 제품·사업 영역을 참고한 분석자의 분류. 사실로 확인한 개인 간 갈등이 아닙니다.
- 연결이 없는 인물도 디렉터리에는 표시됩니다. 근거가 없는 관계를 채우지 않습니다.

인물 직함 일부는 2026-09-22 공개 프로필 확인 기록에 근거하며 시간이 지나면 재확인이 필요합니다. 관계의 수나 화면상 위치·크기는 영향력 점수가 아닙니다.

## 현재 제공 기능

인물/계정 검색, 분야 필터, 관계 종류 필터, 노드와 연결선 선택, 근거 패널, 확대·축소·빈 영역 드래그, 키보드 탐색, 계정 디렉터리, 근거 라이브러리, JSON 내려받기, URL 해시를 통한 탐색 상태 공유, 모바일 반응형 화면.

## 발언 수집

현재 X 게시물·인터뷰 수집, 자동 요약, 푸시 알림은 연결되지 않았습니다. `statements`는 빈 배열이고 화면에 연결 대기 상태를 명시합니다. GitHub Pages 자체는 정적 호스팅입니다. 향후 수집기는 별도 실행 환경에서 원문·시각·출처·인물 ID가 있는 데이터를 생성하고 검토 후 정적 JSON으로 반영해야 합니다. 토큰·쿠키 등 비밀정보를 사이트에 넣지 마세요.
