# Influence Atlas

46개 공개 X 계정을 바탕으로 만든 한국어 인물·기업 관계 대시보드. GitHub Pages용 정적 사이트이며 API 키나 유료 서비스가 필요하지 않습니다.

## 실행

Node.js 20+ / Python 3가 있다면:

```sh
npm test
python -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. `file://`로 열면 JSON을 읽을 수 없으므로 HTTP 서버가 필요합니다.

## GitHub Pages 배포

이 폴더를 저장소 루트로 사용합니다. GitHub 저장소의 Settings → Pages → Source를 **GitHub Actions**로 선택하고 `main` 브랜치에 푸시하면 `.github/workflows/pages.yml`이 테스트 후 배포합니다. 기본 주소는 `https://<owner>.github.io/<repository>/`입니다. 모든 파일 경로는 상대경로이므로 프로젝트 하위 경로에서도 작동합니다.

배포되는 파일은 `index.html`, `styles.css`, `app.js`, `graph.js`, `interactions.js`, `data.json`, `.nojekyll`과 `portraits/`의 인물 사진입니다. 개인 로그인 계정명·알림 설정·작업 기록은 포함하지 않습니다. Google Fonts를 불러올 수 없을 때는 시스템 글꼴로 표시합니다.

## 데이터 편집과 검증

`data.json`의 `nodes`는 관심 계정 46개와 관계 설명용 기업·기관 28개입니다. `edges`는 역할·협력·과거 이력·사업 경쟁을 구분합니다. 각 관계에 출처 URL과 확인 날짜가 있고, 발표 자료에는 발표 당시 날짜도 있습니다. `build-data.mjs`는 초기 데이터 생성 스크립트이며 재실행하면 JSON을 덮어씁니다. 직접 JSON을 수정한 후에는 생성 스크립트를 재실행하지 마세요.

- `affiliation`: 공개 프로필의 역할 또는 창업 이력. 인물 간 지휘·친분을 추정하지 않습니다.
- `partnership`: 공식 발표로 확인한 기업 간 협력·투자. 현재의 모든 계약 조건을 뜻하지 않습니다.
- `history`: 과거 소속.
- `competition`: 공식 제품·사업 영역을 참고한 분석자의 분류. 사실로 확인한 개인 간 갈등이 아닙니다.
- 연결이 없는 인물도 디렉터리에는 표시됩니다. 근거가 없는 관계를 채우지 않습니다.

인물 직함 일부는 2026-09-22 공개 프로필 확인 기록에 근거하며 시간이 지나면 재확인이 필요합니다. 관계의 수나 화면상 위치·크기는 영향력 점수가 아닙니다.

## 현재 제공 기능

인물/계정 검색, 분야 필터, 관계 종류 필터, 노드와 연결선 선택, 근거 패널, 확대·축소·빈 영역 드래그, 키보드 탐색, 계정 디렉터리, 근거 라이브러리, JSON 내려받기, URL 해시를 통한 탐색 상태 공유, 모바일 반응형 화면.

## 발언 수집

현재 X 게시물·인터뷰 수집, 자동 요약, 푸시 알림은 연결되지 않았습니다. `statements`는 빈 배열이고 화면에 연결 대기 상태를 명시합니다. GitHub Pages 자체는 정적 호스팅입니다. 향후 수집기는 별도 실행 환경에서 원문·시각·출처·인물 ID가 있는 데이터를 생성하고 검토 후 정적 JSON으로 반영해야 합니다. 토큰·쿠키 등 비밀정보를 사이트에 넣지 마세요.

## 관계도 조작

아이콘을 드래그하면 연결선도 함께 이동합니다. 아이콘 클릭은 상세 보기, 키보드 방향키는 위치 이동(Shift: 큰 폭 이동)입니다. 빈 공간 드래그로 화면을 이동하고 마우스 휠, 트랙패드 또는 두 손가락 제스처로 확대·축소합니다. 확대 범위는 25–600%이며 포인터 위치를 중심으로 확대합니다.

아이콘 배치는 전체 관계도와 각 분야별로 이 브라우저의 localStorage에 저장됩니다. 페이지를 다시 열거나 관계 필터를 바꾸어도 유지되며 다른 기기와 동기화되지 않습니다. 배율 숫자는 화면 위치와 배율만 초기화하고, ‘배치 초기화’는 현재 분야의 저장된 아이콘 배치도 초기화합니다. 저장이 차단된 브라우저에서는 현재 페이지에서만 유지됩니다.

## 인물사진

인물 37명에 사진을 표시합니다. 34명은 Wikimedia Commons에서 출처·저작자·라이선스를 확인한 썸네일을 portraits/에 저장합니다. 이석희·허이·아서 헤이즈는 공식 소개 페이지의 외부 사진을 참조합니다. 사진별 출처와 이용조건은 data.json의 photo 및 화면의 인물 상세·근거 라이브러리에서 확인할 수 있습니다. 사진은 원형 프레임으로 표시하며 불러오기 실패 시 이니셜을 유지합니다. 외부 원본 주소 변경 시 해당 인물의 photo.url을 갱신하세요.

## 관계 설명

연결 50개에 관계 이름과 문장 설명이 있습니다. 대립·분쟁, 경쟁(해석), 지원·투자, 상하·직무, 협력, 소속·역할, 과거 이력을 구분합니다. 지원과 상하관계만 제공자·상위 책임자에서 상대방을 향하는 화살표로 표시합니다. 인물과 조직의 창업·소속 이력을 개인 간 상하관계로 추론하지 않습니다.

지도 위 관계 이름 또는 아래 설명 카드를 누르면 상세 설명·방향·출처·시점을 확인할 수 있습니다. 유형 버튼을 다시 누르면 모든 관계로 돌아옵니다. 관계 이름은 켜기·끄기가 가능하며 아이콘 드래그 시 선·화살표·이름 위치도 갱신됩니다. 전체 목록은 현재 분야·유형·선택 인물·검색 조건을 따릅니다. 법적 대립 사례는 2025년 3월 당시의 기록이며 현재 소송 상태를 나타내지 않습니다.
